# Mini MicroSD SPI 卡模块（裸板款，18.5×17.5mm）

SPI 接口 MicroSD 卡读写模块，无电平转换、无稳压，纯 3.3V 裸板，6 脚排针直连。选购结论：ESP32-S3 是 3.3V 系统，选此裸板款最省事（对比淘汰的带电平转换大板款需 5V 供电，资料已删除，git 历史可查）。

> ⚠️ 该模块无官方资料，以下参数部分来自商品页、部分为同类公版推断，**标注"待实物确认"的项以到手实物为准**。

## 模块参数

| 项目 | 参数 |
| --- | --- |
| 通信接口 | 标准 SPI（MISO/MOSI/SCK/CS） |
| 电源电压 VCC | **只能 3.3V**（无稳压、无电平转换，直供卡） |
| 接口电平 | 3.3V 直连 |
| 板上元件 | 仅数颗 10K 上拉电阻（照片可见 103 电阻） |
| 卡座 | 弹出式（push-push）金属卡座 |
| 卡类型 | 商品页标 "MINI SD"，**大概率为 MicroSD（TF）槽，待实物确认** |
| 排针 | 6 脚 2.54mm，已焊直针 |
| 尺寸 | 18.5×17.5mm，2 个定位孔 |

## 接线（ESP32-S3）

- VCC → 3V3，GND → GND，MISO/MOSI/SCK/CS → 任意可用 GPIO
- **引脚序待实物确认**：排针丝印在商品照中不可读，到手按板子丝印接线，接前用万用表通断档核对 VCC/GND
- 写卡峰值电流按 ~200mA 留余量（SD 卡本身功耗，与模块无关）

## 使用要点

- SPI 模式实测吞吐约 1~2MB/s，存 JPEG 照片/短 MJPEG 片段够用；高清流畅录像需改 SDMMC 方案（见 ov2640 文档与 #12 讨论）
- SD 卡建议 ≤32GB FAT32 最省心；>32GB 出厂为 exFAT，需格式化成 FAT32
- 无卡检测引脚，检测插卡靠 SPI 初始化成败判断
